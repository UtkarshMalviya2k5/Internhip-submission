# Task 2 - React Single Page Application (SPA)

## 📌 Objective
Build a React Single Page Application (SPA) that consumes a REST API and provides a complete CRUD interface for managing products.


## 🚀 Technologies Used
- React.js
- React Router DOM
- Axios
- Node.js
- Express.js
- MongoDB Atlas
- CSS

## ✨ Features
- Home Page
- Product Listing
- Add Product
- Edit Product
- Delete Product
- React Router Navigation
- Axios API Integration
- Responsive UI
- Loading & Error Handling

## 🛠 Installation

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```
## 🌐 API Base URL
http://localhost:5000/api

## 📡 API Endpoints
| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | /api/products | Get All Products |
| GET | /api/products/:id | Get Product by ID |
| POST | /api/products | Add Product |
| PUT | /api/products/:id | Update Product |
| DELETE | /api/products/:id | Delete Product |
